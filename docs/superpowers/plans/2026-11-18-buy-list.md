# "To buy" List Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mark coins to buy more of with a ☆/★ in the CMC portfolio tables, highlight them, and filter the table to them.

**Architecture:** A pure `lib/favorites.ts` (toggle, tested). The worker owns the list (`favoritesItem`), serves it inside `PageSettings` and handles a toggle message. A content module `entrypoints/content/buyList.ts` renders stars, highlight and the filter toolbar from `main.ts`'s update loop.

**Tech Stack:** TypeScript, WXT MV3, vitest.

**Spec:** `docs/superpowers/specs/2026-11-18-buy-list-design.md`

## Global Constraints

- Stores lower-case tickers only. Never changes the CMC account.
- The content script never reads extension storage: list via `PageSettings`, changes via a message.
- Clicks on our controls never reach CMC's row handlers.
- Work on `release_1.2.0`.

## Review Focus

- **Toggling a star rapidly / in two tabs** → the worker reads the stored list fresh on each toggle; the last answer wins on the page. Task 2 code.
- **CMC re-renders a row (live prices)** → the star and highlight come back, no duplicate stars (idempotent by a key on the star). Manual check.
- **Filter on, then the last marked coin is unmarked** → filter turns off by itself, the table isn't left empty. Task 2 code.
- **Filter on, then navigate to another portfolio** → the new table is filtered too (state is per tab), N is the new table's count. Manual check.
- **Symbol case / spaces** ("ZRO", " zro ") → the same coin. Task 1 test.

- Produces:

- [ ] **Step 1: Worker** — `getPageSettings` adds `favorites: await favoritesItem.getValue()`; on `FAVORITE_TOGGLE_MESSAGE`: read the list, `toggleFavorite`, save, `sendResponse(newList)` (return `true`); `favoritesItem.watch(notifyCmcTabs)`. `pageSettings.ts` `EMPTY.favorites = []`.
- [ ] **Step 2: `buyList.ts` `renderBuyList`** —
