# Release 1.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Native staking rates as a "Wallet" exchange, Telegram price-jump alerts, and yearly income in the totals banner.

**Architecture:** "Wallet" is one more `Exchange` in `EXCHANGES` whose `loadRates()` merges keyless per-network modules, so the cache, Earn column, alerts, digest and income pick it up unchanged. Price jumps are a new step in the worker's scheduled check (`runCheck`) using CMC's public quote API, with CMC ids and position costs saved by the content script. The banner reuses the digest's income calculation, extracted into a shared function.

**Tech Stack:** TypeScript, WXT 0.20 (Chrome MV3), Preact (settings page), vitest (added in Task 1).

**Spec:** `docs/superpowers/specs/2026-11-16-release-1.2.0-design.md`

## Global Constraints

- Public repo: no amounts, balances or portfolio composition in code, tests, fixtures, docs or commits. Fixtures use made-up numbers.
- Only public, keyless endpoints. Native staking only (no liquid staking, lending, vaults).
- Network rates are stored **net of a 10% validator fee**: `apr = gross × 0.9`, one constant `VALIDATOR_FEE = 0.1`, and marked approximate ("≈").
- Exchange id `wallet`, name `Wallet`. The no-rate option is labelled `Other (no rate)`; its stored value stays `none`.
- Jump alerts: default on, default threshold 30 (% since the previous check), no minimum position size, unchecked portfolios left out.
- Never add, edit or delete CMC transactions. Live checks on CMC are read-only.
- UI and Telegram copy in English, plain words. Code style: 4-space indent, existing ESLint config (`npm run lint`), `npm run compile` clean.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **One network down** (e.g. Solana RPC 429): other Wallet coins still get rates; only all-modules-failed marks Wallet as failed. → test in Task 1.
2. **Upgrade with existing baselines:** first check that sees `wallet` sends no "new best rate" alerts caused by it, later checks do. → test in Task 3.
3. **Coin without a CMC id or price** (new coin, delisted coin missing from the quote response): skipped silently, its old baseline kept. → test in Task 7.
4. **Telegram send fails** for the jump message: baselines of those coins aren't moved, so the next check retries. → test in Task 7.
5. **Hidden balances in CMC** (`****`): banner income shows percentages only, no USD. → test in Task 8.
